# Home Todo

Offline-only Android app for home chores and per-store grocery lists.

- Kotlin, Jetpack Compose, Room (SQLite)
- No INTERNET permission. Everything lives on the phone.
- Lessons for each milestone are in `docs/lessons/`.

## Milestones

1. Skeleton and data model
2. Snapshot screen wired to real data
3. Store lists, check-off, multi-store tags, manage stores (add, rename, recolor, reorder, delete with warning)
4. Search and buy again
5. Chores: add, detail, photos
6. Reminders
7. WhatsApp share in and out
8. History
