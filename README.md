# Home Todo

Offline-only Android app for home chores and per-store grocery lists.

- Kotlin, Jetpack Compose, Room (SQLite)
- No INTERNET permission. Everything lives on the phone.

## What it does

1. Snapshot: today's chores, what's coming up, and a tile per store
2. Store lists like a notes app: type and press Enter, tick to strike through, Clear checked, swipe left to delete, quiet suggestions from things you added before, share a list as text
3. Manage stores: add, rename, recolor, reorder, delete with a warning
4. Chores: weeknight, weekend or by a date, repeats, notes, photos from camera or gallery
5. Daily reminder: weekdays 5:30 pm, weekends 9:00 am, only when something is due
6. WhatsApp import: share a message to the app, review the matched items, add them
7. History: completed chores and grocery trips by day

Every push to main publishes a release with the APK: see Releases.
